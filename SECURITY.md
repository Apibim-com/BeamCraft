# Security policy

BeamCraft opens files from untrusted sources (IFC, DSTV, project files). Crashes, hangs, memory
blow-ups and path-traversal bugs on crafted input are treated as security issues.

**Please do not open a public issue.** Use GitHub's private vulnerability reporting
("Security" tab → "Report a vulnerability") on this repository, or email the maintainers at Apibim.

BeamCraft is pre-alpha; only the latest `master` is supported.
